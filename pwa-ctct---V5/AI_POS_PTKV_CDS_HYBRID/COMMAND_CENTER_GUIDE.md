# Command Center Guide

The Command Center is surfaced in Admin → Báo cáo.

It shows:

- total users
- active today
- logged in today
- learning today
- completed topics
- quiz submissions
- average score
- weak learners
- unit summary
- recent activity timeline
- electronic learner profile
- PEQI

If the Apps Script analytics dispatcher is not deployed, the panel shows an honest setup state and existing admin functions continue working.
