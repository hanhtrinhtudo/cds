# Unit Analytics Guide

Unit analytics metrics:

- users total
- active users
- completion rate
- average score
- average learning time
- quiz attempts
- weak learners
- top topics
- low-performing topics
- PEQI average

Scope rules:

- admin sees global scope
- chỉ huy/chính trị viên sees assigned organization scope and descendants when backend scope enforcement is available
- learner sees only self data
