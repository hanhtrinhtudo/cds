# UI Freeze Scope

## Included in UI Freeze RC1

### Product screens

- Authentication
- Dashboard
- Học tập
- Học tập chi tiết
- Kiểm tra / Thi thử
- Tin tức
- Tin tức chi tiết
- Hỏi AI
- Cá nhân
- Kết quả
- Bảng xếp hạng
- Xem lại đáp án when data exists
- Admin static-mode panel

### Navigation and shell

- Header
- Bottom navigation
- Main mobile shell
- Safe-area behavior
- AI full-page workspace shell

### Components

- UI primitives
- Product cards/rows
- AI chat components
- Layout primitives

## Excluded from UI Freeze RC1

- Backend feature expansion.
- Admin content authoring not supported by current Apps Script actions.
- Database/schema changes.
- New AI prompt behavior.
- New exam submission behavior.

## Freeze standard

Post-freeze work must be limited to release-critical visual defects unless explicitly approved as a new sprint.
