# Electronic Learning Profile v2

## Structure

1. Command Summary: identity, unit, role/status, PEQI, completion, average score, review/AI/news counts, latest activity, risk level, primary recommendation.
2. Learning Evidence: real progress props and analytics event histories.
3. Risk Matrix: eight explainable risk checks.
4. Decision Support: concise evidence count, recommended actions and seven-day follow-up.
5. Timeline v2: neutral event labels, resource and timestamps.
6. Commander Actions: six 44px controls creating local drafts only.
7. Case Management: draft cases, status transition and action notes.

## Availability

Analytics health is checked before three concurrent calls: user summary, user PEQI and 30-day event list. Requests are cancelled logically on learner change. If unavailable, account/progress data remains visible and analytics-derived values show no-data states.

## Privacy

AI prompt/response bodies are never shown. Only event category/resource/count/time may be rendered. No token, endpoint or backend identifier appears.
