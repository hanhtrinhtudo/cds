# Learner Profile Analytics

Admin learner profile fields:

- full name
- username
- unit
- role/status
- last login
- total sessions
- topics opened
- topics completed
- learning minutes estimate
- quiz attempts
- average quiz score
- review count
- news views
- AI usage count
- latest activity timeline
- PEQI score
- risk flags

Sprint 7.3 frontend includes the Command Center panel and PEQI display contract. Live data requires `analytics.*` Apps Script actions to be deployed.
